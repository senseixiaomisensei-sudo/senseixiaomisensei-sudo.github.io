PRIVACY

隐私说明

基础工具在浏览器中本地处理；云端深度处理仅在部署启用且你主动点击后调用。

基础工具不会上传

长度检查、标签整理、排版整理、发布可信包和本机 Skill 权限护照都在你的浏览器内完成。我们不会建立账号、保存草稿或把这些基础工具的输入发送给 PostPrep 服务器。

云端深度处理（按部署配置）

基础工具不会上传草稿。若当前部署启用了服务端代理，点击深度建议、深度整理、深度润色、发布可信包的深度建议或按平台生成后，只会发送当前主题或文案来生成结果；使用公开 GitHub Skill 权限护照时，只会发送你粘贴的 GitHub 地址并读取对应公开 SKILL.md。未启用时按钮会提示暂不可用。

RVC 变声与模型训练

只有你主动点击变声或训练后，所选音频才会经受保护网关发送到本机 GPU 服务。普通变声输入在任务排队完成后删除，输出只通过短期随机令牌提供。模型训练会暂存你逐段上传的音频，训练完成、取消或失败后删除训练音频；训练得到的 RVC 模型与索引保存在运行该服务的主机，并显示在“训练完成的模型”独立分区。请勿提交未经授权的声音。

静态资源与人机验证

页面样式、图标和首页图片都使用仓库内置资源。你主动使用云端功能时，浏览器可能请求 Cloudflare Turnstile 验证令牌；Google AdSense 自动广告脚本会在公开页面异步加载。

查看 Cloudflare Turnstile 隐私说明

广告与第三方代码

公开页面使用 Google AdSense 自动广告。Google 及其广告技术合作伙伴可能请求设备信息、IP 地址，使用 Cookie 或本地存储，并依据地区、同意状态和广告设置投放广告。广告不会读取 PostPrep 输入框中的草稿或音频内容。

查看 Google 广告与 Cookie 说明

你的选择

你可以随时清空输入框、关闭页面或清除浏览器的本地站点数据。语言偏好仅保存在当前浏览器的 localStorage 中。
