03 / 06

一切皆插件

模型、工具、手机能力都以原版 dsh / Cordis 插件接入。内置与电脑版 DSH 相同的插件市场（format 1 索引，3900+ 插件，搜索、分类、版本、一键安装），也支持 npm / git / 本地 / ZIP 插件安装、Cordis 配置导入、GitHub 公共配置同步、npm 搜索；插件加载失败被隔离并给出原因。

0.2.0-m2

M2 新增。

01四档审批
手动 / 规则 / 审批模型 / 全自动，规则可按作用域组合，高危操作单独确认；审批模型超时或失败自动回退；通知栏可直接允许、拒绝或本会话允许。
02九种模式
每种模式有自己的工具白名单、只读限制、温度、步数与输出预算。
03零成本联网搜索
无需 API key，多源故障切换，中文查询优先中文源；正文与链接提取、PDF 按需读取、WebView 截图与脚本交互。
04文件交付
原生文件卡，音视频、图片、PDF、ZIP、DOCX 预览，流式保存与分享；大附件最高 1 GiB。
05按需工具
媒体、文档、语音、编译工具按需下载，APK 本体不必全部打包。
06Android 能力桥
@hh/bridge SDK：文件交付/分享、电量、通知、快捷方式、Intent、WebView 渲染。
07自我更新
源码工作副本 → GitHub 远程构建 → 校验 SHA256、包名与签名证书 → 通过 Shizuku 安装，失败回退系统确认；保留三个旧 APK。
08安全与恢复
安全模式、配置快照、备份与原生恢复入口。
