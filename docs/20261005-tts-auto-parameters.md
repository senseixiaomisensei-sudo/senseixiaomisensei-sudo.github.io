## 自动调参

- `assets/rvc-auto-parameters.js` 统一常规和合唱的策略，版本 `register-match-v2`；全局最大移调 ±12 半音。
- 优先使用与当前角色权重 hash 匹配的原声参考中值音高。角色标签仅作为声区回退依据，不把声区识别当作人的性别识别。
- 高置信度输入做更主动的跨声区匹配；证据不足保持原调。复杂／高音范围使用自动 F0；宽音域限制检索强度；更强清辅音保护；保留动态；不增加 F0 中值滤波。
- 常规按用户点击上传分析；复用现有持久任务与鉴权，不调用多人分离推断。歌曲先分离人声，再测声区，避免从伴奏猜测人声音高。纯人声先经 FFmpeg 解码，支持手机录音容器。
- 分析中断后恢复已有任务；按原始 File 和模式缓存分析证据。选择新角色复用声区，不重复上传。手动参数、音量与独立静音优先；无自动归一化抵消用户增益。
- 新版讲话引擎保留已验证的独立角色参考与 100 步生成，不强制切换回 RVC，也不谎称禁用的 RVC 控件会影响新版引擎。
- 匹配声区不保证所有素材都无沙哑或伪影；歌曲移调会改变调性。不能将这些功能测试作为全部角色主观音质通过的证明。
