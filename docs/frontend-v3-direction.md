# PostPrep v3 · 设计方向（重做版）

> 一句话：**内容是主角，玻璃只是手。** 页面像一张安静的纸，产品本身摊在上面；玻璃只出现在你要伸手去碰的地方——导航、工具栏、分段控件、播放条——并且它下面一定有东西可以被折射。

v3 第一版的问题不是"不够炫"，而是"像 AI 做的"：紫青霓虹、渐变字、漂浮球、数字堆、药丸、霓虹波形、居中营销腔。它们全部删除，并写进下面的禁用清单，以后不得回流。

---

## 1. 原则（按优先级）

1. **一眼看懂**。首屏就是产品在工作：一段真实的小红书文案在编辑器里被逐字检查。不解释"我们是什么"，直接演示"它在帮你干什么"。
2. **美感 = 性能**。一切动效只动 `transform` / `opacity`；滚动叙事交给 CSS `animation-timeline`，不支持就用 IntersectionObserver 一次性触发；滚动事件里不写样式。卡顿就是丑。
3. **玻璃只在控件层**。内容层永远不透明、不模糊。整页不铺玻璃卡片。
4. **折射必须看得见**。玻璃下方必须是文字、波形、色块。下面是纯色就不用玻璃，用实心控件。
5. **少而极致**。每页只留一个"记得住的瞬间"，其他地方克制到近乎无聊。
6. **物理而不是特效**。弹簧（真实 stiffness/damping）、可打断、跟手；没有循环播放的装饰动画。

## 2. 禁用清单（AI 味）

紫/青/粉霓虹；大面积渐变背景与极光；渐变色文字；漂浮的发光球；"8 个工具 / 0 次登录 / 100%"式数字堆；药丸徽章串；装饰性波形与柱状条；彩色发光阴影（glow）；通篇居中的营销文案；Emoji 当图标；无意义的点阵网格背景；"✦"星芒；把每块内容都装进玻璃卡。

## 3. 色板

只有一种强调色，其余颜色只来自内容（检查结果的状态色、波形）。

| Token | 亮色（默认） | 深色（OLED） | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f5f4f0` 暖纸灰 | `#000000` | 页面底 |
| `--paper` | `#fcfbf8` | `#0e0e10` | 编辑器、内容面 |
| `--ink` | `#1d1d1f` | `#f5f5f7` | 主文字 |
| `--ink-2` | `#55555c` | `#a1a1a6` | 次文字（≥4.5:1） |
| `--ink-3` | `#76767d` | `#86868b` | 注释、标签（≥4.5:1 on bg） |
| `--line` | `rgb(0 0 0 / .1)` | `rgb(255 255 255 / .14)` | 发丝线 |
| `--accent` | `#0a66d8` | `#3d8bff` | 唯一强调色：链接、选中、焦点、进度 |
| `--ok` | `#1f8a4c` | `#32d074` | 内容状态：通过 |
| `--warn` | `#b25e00` | `#ffb340` | 内容状态：注意（极限词） |
| `--bad` | `#c9302c` | `#ff5a52` | 内容状态：超限、重复 |
| `--tag` | `#0a66d8` 底 8% | 同 | 话题标签高亮 |

状态色只出现在被检查的文字上（下划线、底色），不出现在装饰上。录音棚面板是唯一的大块深色（真实设备质感），在亮色页面中像一台摆在纸上的机器。

## 4. 字体

- 栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "HarmonyOS Sans SC", "MiSans", system-ui, sans-serif`；数字 `font-variant-numeric: tabular-nums`；等宽 `ui-monospace, "SF Mono", Menlo`。
- 字号阶梯（clamp，桌面/手机）：Display 96/44，H2 56/32，H3 24/20，Body 19/16，Small 14/13，Micro 12（大写英文 kicker 弃用，改为中文小标题）。
- 标题：字重 600，`letter-spacing: -0.035em`（中文 -0.02em），行高 1.04；正文行高 1.6，中文行长 ≤ 34 字，英文 ≤ 68ch。
- 中文标点挤压：`text-spacing-trim: trim-start; font-feature-settings: "halt"` 仅用于标题；`line-break: strict; word-break: keep-all` 在标题上避免孤字；`text-wrap: balance` 标题，`pretty` 正文。
- 标题大而安静：无渐变、无描边、无阴影，只靠尺寸和留白。

## 5. 版式网格

- 12 栏，最大内容宽 1180px，栏间距 24px；页边距 `max(20px, 5vw)`。
- 垂直节奏 8px 基线；区块间距 `clamp(96px, 14vw, 200px)`。
- 文案左对齐（不居中），标题占 7 栏，说明占 5 栏——典型的 Apple 产品页左文右图或上文下"设备"。
- 手机：单栏，设备画面满宽减 16px，控件触控区 ≥ 44px。

## 6. 组件

- **玻璃（控件层）**三级：
  - `webgl`：仅录音棚播放条（下面是真实波形 canvas，可直接作为纹理折射）；画布 = 控件包围盒，DPR ≤ 2（手机 ≤ 1.5），不可见即停，首次交互后才初始化；
  - `css`：`backdrop-filter: blur(14px) saturate(1.8)` + 1px 内高光 + 0.5px 外描边 + Chromium 下 `url(#lens)` SVG 位移（只在静止且精细指针时启用）；
  - `lite`：不透明面板（减少透明度 / 省流量 / 弱设备）。
- **导航条**：顶部悬浮玻璃胶囊，滚过内容时折射下方文字；当前页指示器是一个液滴，在导航项之间弹簧移动并按速度横向拉伸。
- **分段控件**：同一液滴滑块（stiffness 520 / damping 34），拖动可跟手，松手吸附；按下 scale .96。
- **按钮**：主按钮实心强调色胶囊；次按钮发丝线描边；按下弹性形变（scaleX 1.04 / scaleY .94 → 弹回）。
- **编辑器**：纸面卡，内含真实 `<textarea>` + 同步高亮镜像层（极限词波浪下划线、话题蓝底、重复话题删除线、超限部分红底）。
- **计量**：细线进度（2px），数字等宽滚动。
- **录音棚**：深色铝面板；波形（原声灰 / 转换后强调色）、频谱、A/B 分割、时间码、峰值表；玻璃播放条浮在波形上。

## 7. 动效清单（全部 transform/opacity）

| 名称 | 触发 | 参数 | 降级 |
| --- | --- | --- | --- |
| 首屏编辑器打字演示 | 加载后空闲、可见时 | 每字 38–70ms 人类节奏，用户一碰即停并交还控制 | reduced：直接显示完整文案 |
| 检查标记出现 | 文案变化 | opacity + scaleX 下划线 180ms | 无动画 |
| 分段液滴 | 点按/拖动 | spring 520/34，速度拉伸 ≤ 1.35× | reduced：直接到位 |
| 导航液滴 | 悬停/当前页 | spring 420/32 | 同上 |
| 分镜（4 个工具在同一设备画面） | 滚动 | `animation-timeline: view()`；不支持→IO 设 `data-step` | 静态四宫格 |
| 标题入场 | 进入视口 | translateY 24px→0 + opacity，一次性 | 无 |
| 按钮按压 | pointerdown | scale 弹簧 | 无 |
| 页面切换 | 跨文档 View Transitions | 导航条保持 `view-transition-name`，内容淡入上移 12px | 关闭 |
| 录音棚 A/B 分割 | 拖动 | 跟手，无延迟 | — |
| 播放条折射 | 播放/指针 | WebGL 折射波形，色散 ≤ 1.5px | CSS 模糊 |

## 8. 每页草图

- **首页**
  1. 首屏（记得住的瞬间）：左上小字"PostPrep"，大标题"发之前，先过一遍。"，一句说明，两个按钮。右侧/下方是一台"编辑器设备"：顶部浮着玻璃工具栏（平台分段：小红书 / 抖音 / 公众号 / Instagram + 字数计），编辑器里一段咖啡店探店文案正被打出来，极限词"最好喝""第一"被标黄，重复话题被划掉，超出平台标题上限的字被标红。用户可以直接改文字、切平台，实时重算。
  2. 分镜：同一台设备画面，滚动时依次演示 长度 → 标签 → 排版 → 可信包；左边一行字说明这一步。
  3. 工具目录：八个工具排成一张安静的目录（名称 + 一句话 + 箭头），悬停时整行轻微右移，无卡片。
  4. 录音棚预告：深色面板 + 真实形状波形 + 玻璃播放条，"进入录音棚"。
  5. 隐私：一段话，左对齐，大字。
- **工具页**（长度/标签/排版/生成/可信包/Skill 护照/Skills/隐私）：纸面底；页头标题大而安静；表单区是不透明纸卡；结果数字等宽；导航液滴就是每页共有的那个"瞬间"，长度检查页额外有字数细线计量。
- **变声器**：顶部标题，下面是深色录音棚面板——波形、频谱、A/B、时间码、峰值，玻璃播放条浮在波形上方折射波形（瞬间）。原有工作台表单为纸卡。
- **404**：一行大字"这一页没有发出来。"+ 编辑器里一段被删除线划掉的网址，返回首页按钮。

## 9. 性能预算（硬指标）

- 首页滚动/拖动 60fps（120Hz 设备 ≤ 8.3ms 帧）；主线程长任务 < 50ms；首屏 v3 JS < 80KB gz（另计站点原有脚本，报告单列）；DOM < 800；CLS < 0.05；首屏无大图。
- 不在 scroll 事件写样式；不在 `<html>` 上滚动中切类；`content-visibility: auto` 用于首屏以下区块；`will-change` 只在拖动期间设置。
- 测量：Playwright + CDP，412×915 移动仿真，CPU 4×/6× 降速，记录帧时间、长任务、Recalc Style、LCP/CLS/TBT，写入 `docs/frontend-v3-perf.md`。
