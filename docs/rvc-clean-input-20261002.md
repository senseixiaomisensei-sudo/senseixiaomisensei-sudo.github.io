## 确定的软件 Bug 与修改

`assets/rvc.js::setupEventListeners()` 的“男声变女角色”按钮，错误地把 `model.defaultPitch` 当成跨音域预设。31 个公开角色的中性默认均为 0，所以选角色后该按钮被显示成 (+0)，点击仍设置 0。

现在显式跨音域按钮设置 +12；`applyCharacterPitch()` 使用相同的预设值更新标签。角色选择仍保留当前移调；原调与 -12 按钮仍可明确选择。歌曲旋律不自动改动。改正“0 对所有输入都是安全值”的提示，说明低音讲话转换高音声线时可能需要跨音域试听。

这修复了按钮失效，**不代表所有模型、歌曲与讲话音质已达标**。不是默认给所有角色或歌曲强行升八度。
