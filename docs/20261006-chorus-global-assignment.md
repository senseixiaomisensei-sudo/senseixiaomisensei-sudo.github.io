# 合唱全曲声部归属修复

《口哨》是用户确认的双人失败原样本。保持原角色体系与前端卡片，修改实际分离与声部排列；自动模式仍不凭语气/音高变化推断三四人。

## 原因与修改

`chorus_worker.py::split_pair()` 原先只比较相邻 2 秒重叠波形。全曲交替演唱或弱声重叠时，这不足以维持一致声部归属。《口哨》的完整 UNMIXX 输出与 MedleyVox 输出不具备一一对应关系。

新增全曲学习式参考辅助排列：只有两套估计均满足现有有效声部检查、原对应关系失败时才重试。`chorus_quality.py::reference_assignment()` 用整段当前窗口匹配，证据弱时回到原重叠匹配。它只排列 UNMIXX 的原始估计，不混入参考音频、不重采样、不改变时长、音调或音色。不能匹配的估计仍不强行通过。

辅助排列的结果显示为待试听的两路候选，记录 `assignmentAssisted`，不将其算作独立的人数确认；`humanCountVerified=false`。声音是否为两位真实歌手、是否已无串音，仍须实际听评，不能由相关系数证明。

候选资源由作者 `vocals 200` 升至 `vocals 238` 的 EMA 权重。主模型仍保留 UNMIXX：它在现有有真值双人片段上优于候选，不为升级数量强行全部换成较差结果。

## 验证范围

证据保存在 `E:\大肥鱼\TTS与合唱修复\20261006`。使用完整约 201.41 秒《口哨》，没有只挑成功片段；该曲的真实人数来自用户，未提供独立干净声部真值。

有独立声部真值的验证为 MedleyVox 数据集 The Silver Sea 的 30.75 秒片段，不能当作完整歌曲。UNMIXX 两路平均 SI-SDR 15.808 dB，辅助排列未改变该样本；候选 200/238 分别约 12.913/13.069 dB，仅一个片段的小幅提升，不是通用领先证据。

该片段的两条独立原人声分别跑自动模式均保持一路；已确认单人 Serena TTS 也保持一路。没有把未知身份的历史录音当成单人真值。声纹探索没有充分区分所有演唱变化，因此不把一个声纹阈值部署成万能人数识别。

4 秒窗口、加长重叠、连续 Medley 推理、二次神经残差清理未带来可靠改善，均未启用。没有用压暗高频、移调或频段拆分冒充分离。
