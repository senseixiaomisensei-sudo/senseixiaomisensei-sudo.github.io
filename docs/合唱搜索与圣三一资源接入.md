# 合唱搜索与圣三一资源接入

合唱的每张声部卡片拥有独立的角色搜索、原声试听、转换后试听及参数。搜索支持中文、英文、日文别名和学校名；筛选结果不改变已选择的角色，也不覆盖手动移调。键盘导航只滚动候选列表，避免将整个工作台滚走。

本轮新增 19 套圣三一 RVC 权重与匹配索引：日富美、鹤城、莲见、铃美、爱莉、花江、好美、真白、梓、花子、夏、玛丽、忧、日向、和纱、美祢、樱子、渚、一花。原有 31 个角色 ID、资源与收藏映射保留。圣三一目录包含 26 个人物，已接入 24 个音色；志美子、拉布仍缺少可用资源。

来源固定为 [LordDavis778/BlueArchivevoicemodels](https://huggingface.co/LordDavis778/BlueArchivevoicemodels/tree/263891b78604c12149b92678354c23a2590d39f0)。每个新增角色的 checkpoint/index hash、来源、ONNX hash、分片 hash、参考原声 hash 和版本均记录在 `assets/rvc-models.json`。`models/manifest.json` 记录浏览器资源；资源路径包含实际 ONNX hash，避免仅按日期失效缓存。来源仓库的许可声明记录为元数据，不代表已独立核实所有上游作者的授权。

导出器使用受限 checkpoint 加载、匹配索引维度检查和显式随机激励。19 套模型已通过真实讲话特征下的原生推理与 ONNX 数值比较、不同长度及有限值检查。数值检查不构成音质、自然度或角色身份听评通过。

真实公网合唱任务验证了日富美与一花的请求参数、实际参数、权重/索引 hash，以及两路原声和两路转换后 MP3 的 Range 播放。控制器回归覆盖独立搜索、空结果、中文输入法、键盘操作和手动移调保持。浏览器安全检查未授予访问，因此真实浏览器渲染、触摸手势与 iPhone 实机显示仍未验证；新增角色的完整音质听评也未验证。
