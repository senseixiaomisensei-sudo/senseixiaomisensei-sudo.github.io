# 局部重复人声：定位与修复

上一版 b83473c 的完整《口哨》被用户判为失败，明确位置为开头 7–9 秒，后段也有重复。不能把跨模型归属一致当成无串音。

## 实际原因与修改

`chorus_quality.py::pair_quality()` 的整曲指标只在两路有足够能量的共同活动区计算相干度。7–9 秒较弱路/主要路的能量比约 0.00218，低于活动区门限，因而没有报告串音。手动人数模式原来也会在全曲标志为 false 时跳过独立模型。

原始 UNMIXX 解码输出与重建补偿后差异约 −139 dB，相同内容已经存在于原始分离估计。末端补偿不是该样本的主要原因。独立 MedleyVox 238 EMA 在相同输入的 7–9 秒较弱路 RMS 为 0.00001556，主模型为 0.0044941。不是重新命名或重复下载模型。

`refine_local_leakage()` 使用一一对应的全曲分离参考，逐 500 ms 窗口核对同一主要波形、相关的低电平副本及独立模型的明显改善；局部选择独立模型推理出的完整两路，不施加噪声门，不按频率/音高拆人，不把弱路强制清零。两套估计之间使用 200 ms 互补过渡。不同内容的弱第二声部不能仅因音量低就触发替换。手动/自动人数均运行独立检查。

API 保存并返回 `localLeakageRefinement`，包含选择区间、两模型 hash、对应证据与实际能量比。选择过的候选保持需要审阅状态。

## 真实音频验证

完整《口哨》离线选择了 30.25 秒局部区间。7–9 秒弱路 RMS 从 0.0044941 降至 0.00008568（约 34.4 dB），主声部重新归入对应一路。两路相加的最大差异 1.19e−7，长度未改变。这里只能证明已测同内容泄漏显著降低，不能代替整首听评。

MedleyVox 的 The Silver Sea 双人真值片段：原输出保持逐样本不变，平均 SI-SDR 仍为 15.808 dB。第二位真人声部分别降为 −9.897 dB 与 −20 dB 后进行真实 GPU 分离，局部选择未触发，两路 SI-SDR 均无倒退。后者较弱声部 SI-SDR 仅 3.264 dB，说明原模型能力仍有限，不能写成完美分离。

19 项人数/分离契约、5 项混音契约、3 项上传契约测试通过；真实线上原文件重新上传和部署版本见工作区交付报告。单元测试不代表听感通过。

## 边界

《口哨》没有独立歌手真值轨，本轮不能给出真实歌手 SI-SDR，不能保证所有重唱/同音高区域完全消除串音。没有把每个低电平片段都当作静音，也没有宣称已经获得用户的新版听评通过。
