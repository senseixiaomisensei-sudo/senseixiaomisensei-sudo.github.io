# 静音边界修复：2026-10-02

本次只修正已有 `audio_activity.py` 的静音保护边界，不新增通用音质滤镜，不修改角色、F0、检索、模型或 UI。整首严重金属音、沙哑和破音仍未验收通过。

## 已复现的缺陷与修改

- `classify_activity()` 的形态学腐蚀把文件外视为非静音，导致源音频开头、结尾的确定静音仍保留 180 ms 单位增益。文件外没有需要保护的相邻演唱，因此改为静音边界；文件内部起声与句尾的 180 ms 保护区保留。
- `suppress_silent_synthesis()` 将最后一个包络帧之后的增益恢复为 1，可能重新放出最后不足 10 ms 的合成杂音。现在沿用最后一个实际增益值。
- 仍只抑制持续接近数字零（源 RMS ≤ 1e-6）的核心区；弱声和清辅音不因 F0 状态被清零。
