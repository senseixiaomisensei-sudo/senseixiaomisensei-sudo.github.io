# 2026-09-19 奥德赛目录与共用音频链修复

## 已完成

- 添加奥德赛（奥德修斯）海洋学院分组及渡海心、渊上琴音目录。两者为**待接入**，不会假装有可选音色。
- 移除普通语音和大音量输入上无条件运行的 FFT 降噪，避免对干净谐波再次加工。
- 输入及各输出保护滤镜补偿限幅器前视延迟，避免瞬态错位和尾部丢失。
- 恢复按输入特征选择输出保护：高能量、高音/复杂音高及已知刺耳模型分别使用已有保护配置；普通输出也保留点击与高频保护。
- 中间输出保留浮点格式；保护滤镜失败时返回错误，不再放行未经保护的音频。最终真峰值保护继续覆盖全部角色及歌曲模式。
- CI 检查超时由 10 分钟调整为 20 分钟：上次网站部署成功，但独立检查因拉取大模型仓库占用时间而取消。

## 来源核实及接入限制

角色资料：https://gamewith.jp/gamedb/6253/articles/62411

该资料包含官方发布链接及学院、人物介绍。公开检索采用中日英名字，并查询 Hugging Face 模型 API、`ryzusaku/rvc_v2_models`、`Ilzhabimantara/rvc-Blue-archives-hoyogames` 的实际目录。未找到可验证的渡海心、渊上琴音或小森澄香 RVC 权重与索引；找到的相关图像 LoRA 不适用于语音转换。因此本次没有新增奥德赛可用声线，也没有将其他角色音色改名冒充。

## 可复现证据

- 随机瞬态夹具输入滤镜互相关延迟：修复前 29.975 ms，修复后 0 ms；输出帧数保持不变。
- 440 Hz 主体与 14 kHz 压力信号：高频/主体比由 -4.44 dB 降至 -13.46 dB，相邻采样最大变化由 0.281 降至 0.107。这是滤镜压力测试，不代表所有真人输入的听感评分。
- `tests/test_voice_input_quality.py` 检查输入时序、呼吸、安静环境、风声与静音。
- `tests/test_output_harshness.py` 检查四种输出配置的时序，以及高频抑制和主体保留。
- 本机验收资料：`E:\大肥鱼\网站音色修复\20260919\验收`。全角色夹具由已有普通语音、高音颤音、大音量语音及静音段组成，检查真实转换结果的有限值、削波、时长和非静音。

这些检查覆盖已复现的共用链路问题，不能证明任意录音、极端移调或模型训练缺陷都已消除。此前已经削波的输入也不能靠限幅恢复。
